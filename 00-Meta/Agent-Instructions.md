# Instrukcje dla agentów AI

- Vault jest prowadzony po polsku.
- Nie twórz faktów bez wskazania źródła.
- Nie zmieniaj istniejących `uid`.
- Nie usuwaj dokumentów ani notatek bez wyraźnej zgody użytkownika.
- Dla każdego nowego faktu utwórz lub podłącz źródło.
- Oznaczaj niepewność i konflikty.
- Zachowuj stronę lub zakres stron dokumentu.
- Używaj wikilinków dla osób, miejsc, wydarzeń i źródeł.
